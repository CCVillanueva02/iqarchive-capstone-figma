# IQArchive RBAC — Updated Role Structure

## The 7 Roles (Clarified)

### 1. System Administrator
- Manages user accounts, system configuration
- Full access to audit logs
- No involvement in accreditation content decisions

### 2. IQA Staff / IQA Member
- initiates ALL stage transitions
- Consolidates evidence across colleges
- Reviews and approves document uploads
- Manages the master accreditation calendar/timeline

### 3. College Dean
- **Dual role**
  - **As College Dean:** Approves evidence uploads from their college's programs (gatekeeper before IQA sees it), views college-wide dashboard
  - **As Task Force Lead (automatic elevation):** Because Deans are automatically the Task Force lead for their college, they also inherit Task Force permissions — can assess AACCUP criteria, work directly on evidence like any Task Force member

### 4. Task Force Member
- Subject-matter experts assessing AACCUP instruments
- Upload and organize evidence per assigned area
- **College Dean is automatically part of this group** (as lead) — contextual elevation, not a separate permission set

### 5. Internal Accreditor 
- Mock/rehearsal accreditation reviewer — simulates what the external AACCUP accreditor will see, before actual submission
- **What they do:**
  - Review compiled evidence as if they were the external accreditor
  - Leave comments/annotations on specific criteria or documents ("This evidence doesn't clearly show compliance with Criterion 3.2")
  - Flag gaps or weaknesses for Task Force / IQA to address
  - Comments are visible to IQA Staff and relevant Task Force members

### 6. BU Executive
- University-wide read-only dashboard (all colleges)
- No approval authority, informational only

### 7. External Accreditor
- The real AACCUP panel member
- Limited, read-only access to final submitted evidence
- Access only after Stage 8 (Submitted)
