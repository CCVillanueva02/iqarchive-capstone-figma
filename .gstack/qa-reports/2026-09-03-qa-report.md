## Documented Findings & Issues

### ISSUE 1: Uncaught `TypeError` in Legacy `iqa-documents.js`
* **Severity:** **HIGH**
* **Category:** Functional / Console Cleanliness
* **Route:** `/roles/system-administrator/documents`
* **Evidence:**
  ```
  [ERROR] Error fetching colleges: TypeError: Cannot read properties of undefined (reading 'college_id')
      at http://[::1]:5173/resources/js/iqa-documents.js:3040:65
  ```
* **Root Cause:** When an administrator or user without an assigned program opens the documents workspace, `userProgram` is null. The client script evaluates `userProgram.college_id` without null-coalescing/optional chaining (`userProgram?.college_id`).
* **Repro Steps:**
  1. Log in as `system-administrator` via `/dev/login/system-administrator`.
  2. Navigate to `/roles/system-administrator/documents`.
  3. Inspect the browser console.

---

### ISSUE 2: Duplicate Named Route Collision `'documents.serve'`
* **Severity:** **MEDIUM**
* **Category:** Routing / Architecture
* **Location:** [`routes/web.php:311`](file:///c:/Users/janss/Herd/iqarchive/routes/web.php#L311) & [`routes/web.php:332`](file:///c:/Users/janss/Herd/iqarchive/routes/web.php#L332)
* **Evidence:**
  ```
  GET|HEAD documents/{id}/serve .. documents.serve › SubmissionController@serveDocument
  GET|HEAD documents/{id}/view  .. documents.serve › DocumentCategoryController@serveDocument
  ```
* **Impact:** Route generation using `route('documents.serve', ...)` is non-deterministic and can generate unexpected URLs depending on controller registration order.
* **Fix Recommended:** Rename line 332 to `documents.view`.

---

### ISSUE 3: Sidebar Scroll Restoration Alpine Error
* **Severity:** **LOW**
* **Category:** Console / UX
* **Routes:** Global (App Layout Sidebar)
* **Evidence:**
  ```
  [WARNING] Alpine Expression Error: this.$nextTick is not a function
  [WARNING] Alpine Expression Error: hasMoreBelow is not defined
  ```
* **Root Cause:** Sidebar template calls `this.$nextTick(...)` inside an inline Alpine directive where `$nextTick` is accessed on an unexpected context, and references uninitialized variable `hasMoreBelow`.
