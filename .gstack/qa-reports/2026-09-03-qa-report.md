## Phase 3 Architectural Fix Matrix

| Item | Problem | Fix Applied | Verification | Status |
| :--- | :--- | :--- | :--- | :---: |
| **1. Route Collision** | Duplicate route name `'documents.serve'` on line 332 collided with line 311. | Renamed line 332 to `'documents.view'`, implemented `serveDocument($id)` in `DocumentCategoryController` with authorization. | Regression tests passing; zero route collisions. | **VERIFIED** |
| **2. `basename()` Guards** | `storeAs()` returning false or null `$doc->file_path` caused runtime exceptions in `basename()`. | Added storage failure checks (500 response) and guarded against null/empty file paths before `basename()` / `pathinfo()`. | Storage download tests pass; empty paths return clean 404s. | **VERIFIED** |
| **3. Active Visit Constraint** | Duplicate active accreditations were possible for a single academic program. | Added virtual column `active_program_id` with `UNIQUE` index in MySQL & SQLite + application-layer guard in `ScheduleAccreditation.php`. | `cannot schedule duplicate active accreditation for the same program` regression test passes (Pest). | **VERIFIED** |
| **4. Soft Deletes** | Deleting documents or accreditations destroyed foreign keys and audit history. | Added `deleted_at` migrations to `documents` and `accreditations` tables + `use SoftDeletes;` traits on models. | Migrations executed; models respect soft delete semantics. | **VERIFIED** |
| **5. RBAC Harmonization** | Fragmented `$user->role` checks and 20+ repeated closures in `routes/web.php`. | Created reusable `EnsureUserHasRole` middleware (`'role'`), consolidated closures, updated role checks to `$user->hasRole(...)`. | `RoleRefactorTest` validates multi-role access and 403 blocks across dashboards. | **VERIFIED** |
| **Sidebar Navigation** | Alpine.js `this.$nextTick` and `hasMoreBelow` scope error in sidebar. | Moved `x-data` to wrapper div and fixed injected `$nextTick` call. | Browser console verified 100% clean (0 errors, 0 warnings). | **VERIFIED** |
