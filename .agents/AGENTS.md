# AI Agent Guidelines — IQArchive Codebase

## Design System & Token Enforcement Rules

All AI coding assistants (Antigravity, Claude, Copilot, Cursor, ChatGPT, etc.) working on the **IQArchive** codebase MUST strictly adhere to the centralized design tokens defined in `resources/css/app.css` (`@theme` block).

---

### Mandatory Rule: No Raw Colors or Arbitrary Font Sizes

> [!IMPORTANT]
> **NEVER** hardcode raw hex colors (e.g. `#1b355a`, `#002B61`, `#f27224`, `#F47920`, `#f4f6fa`, `#f8fafc`) or arbitrary font-size utility classes (e.g. `text-[9px]`, `text-[10px]`, `text-[11px]`, `text-[13px]`, `text-[20px]`) in Blade templates (`resources/views/**/*.blade.php`), Livewire components, or JavaScript files.
> 
> Always use the centralized utility classes generated by the `@theme` block in `resources/css/app.css`.

---

### 1. Color Token Mapping (`resources/css/app.css`)

Use these pre-defined utility classes for backgrounds, text colors, borders, rings, and hover states:

| Role / Intent | Tailwind Utility Class | CSS Variable Reference | Raw Hex Equivalent |
| :--- | :--- | :--- | :--- |
| **Primary Navy** | `bg-primary`, `text-primary`, `border-primary` | `var(--color-primary)` | `#1b355a` |
| **Primary Hover** | `bg-primary-hover`, `hover:bg-primary-hover` | `var(--color-primary-hover)` | `#003e8a` |
| **Primary Dark** (Header / Sidebar) | `bg-primary-dark`, `text-primary-dark` | `var(--color-primary-dark)` | `#002b61` |
| **Primary Dark Hover** | `hover:bg-primary-dark-hover` | `var(--color-primary-dark-hover)` | `#001d42` |
| **Primary Light** | `bg-primary-light`, `text-primary-light` | `var(--color-primary-light)` | `#0056b3` |
| **Primary Muted Text** | `text-primary-muted` | `var(--color-primary-muted)` | `#7a8b9e` |
| **Brand Accent Orange** | `bg-brand-orange`, `text-brand-orange`, `focus:ring-brand-orange` | `var(--color-brand-orange)` | `#f27224` |
| **Brand Orange Hover** | `hover:bg-brand-orange-hover` | `var(--color-brand-orange-hover)` | `#d65f1a` |
| **Subtle App Background** | `bg-surface-subtle` | `var(--color-surface-subtle)` | `#f3f7fa` |
| **Card / Select Background** | `bg-surface-card` | `var(--color-surface-card)` | `#f8fafc` |

*For standard status badges, use Tailwind palette utilities:*
- **Verified**: `bg-green-100 text-green-700 border-green-200`
- **Pending**: `bg-amber-100 text-amber-800 border-amber-200`
- **Rejected**: `bg-rose-100 text-rose-700 border-rose-200`

### 2. Typography Token Scale (`resources/css/app.css`)

Use these utility classes for all font sizing across UI elements:

| Typography Role | Utility Class | Rem Value | Pixel Equivalent | Typical Usage |
| :--- | :--- | :--- | :--- | :--- |
| **Micro Label** | `text-label-xs` | `0.625rem` | `10px` | Active badges, tiny inline tags |
| **Small Label** | `text-label` | `0.75rem` | `12px` | Table headers, category uppercase tags |
| **Body Small** | `text-body-sm` | `0.875rem` | `14px` | Form inputs, secondary buttons, helper text |
| **Body Standard** | `text-body` | `1rem` | `16px` | Main body copy, navigation links, primary inputs |
| **Heading Small** | `text-heading-sm` | `1.125rem` | `18px` | Section headers, card titles |
| **Heading Standard**| `text-heading` | `1.5rem` | `24px` | Subheadings, modal titles, brand titles |
| **Heading Large** | `text-heading-lg` | `1.875rem` | `30px` | Page titles, main dashboard headers |
| **Hero Title** | `text-hero` | `3rem` | `48px` | Landing page main hero titles |

---

### 3. Verification Commands for AI

Whenever making style, template, or CSS updates:
1. Build client assets: `cmd /c npm run build`
2. Run test suite: `cmd /c php artisan test`
