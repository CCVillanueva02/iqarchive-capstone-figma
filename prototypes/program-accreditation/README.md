# Program Accreditation UI Prototype

Standalone React prototype for the IQArchive Program Accreditation workflow.

## Run locally

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

The prototype includes college and program selection, Narrative Profile and Program Performance Profile tabs, all ten AACCUP areas, progress tracking, search, an area detail drawer, and a link to the official PPP template.
